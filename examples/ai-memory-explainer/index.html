Recap

Token

A small chunk of text. About 100 tokens make 75 English words.

Context window

Everything the AI can see at once. It has a fixed size.

Summarization

Shortening text you ask about. The original stays.

Compaction

Swapping the old chat for its summary to free up room.

Code on files

Big files stay outside. Only the code and the answer come in.

Sub-agents

Helpers with fresh windows that send back short reports.

Prompt caching

Reusing the unchanged start of the window. Write once, read cheaply.

Thinking effort

How much step-by-step work happens before the answer.

Human in the loop

You approve the steps that are risky or can't be undone.
