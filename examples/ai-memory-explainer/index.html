Recap

Token

A small chunk of text. About 100 tokens make 75 English words.

Context window

Everything the AI can see at once. Fixed size. Anything outside it doesn't exist for the model.

Summarization

Rewriting something long as something short, keeping the key facts.

Compaction

Summarizing the older conversation to free up room. Small details can be lost.

Thinking effort

How much step-by-step work happens before the answer. More effort: slower, more careful.
